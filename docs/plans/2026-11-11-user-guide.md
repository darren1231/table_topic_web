# 實作計畫：網站內的使用說明書

- 日期：2026-11-11
- 分工：Claude 撰寫規格與繁體中文內容，Codex 實作與翻譯
- 目標：使用者在網站內就能看到「這個網站能做什麼、怎麼使用」，並隨介面語言切換成四種語言。

## 已確定的設計

1. **形式**：網站內的一個畫面 `guideView`，與首頁、練習、複習、日曆、成績趨勢同一種畫面切換方式。
2. **入口**：首頁 `home-hero` 區塊中，「今天想練什麼？」標題的**上方**，放一個按鈕或連結，文字為「使用說明書」（四種語言各自翻譯）。點下去切換到說明畫面。
3. **網址**：`#guide` 可以直接打開說明畫面，方便分享。加入 `navigateTo` 允許的畫面清單與初始 hash 判斷。注意不要影響 Supabase 登入回呼使用的 hash（`hasPendingAuthCallback`）。
4. **返回**：說明畫面最上方與最下方各有一個「回到首頁」按鈕；最下方另有「開始練習」按鈕，進入即興問答。
5. **語言**：所有文字使用 `t(key)`，key 以 `guide.` 開頭，四個語系檔都要有完整內容。切換語言時，說明畫面要立即換成新語言（含標題與段落）。
6. **範圍**：只寫一般使用者會用到的功能。不寫管理員後台、不寫自備金鑰。
7. **複習卡**：依**目前 `main` 的做法**撰寫（分析後手動勾選「加入複習」）。PR #45 合併時再更新這一段。
8. **不放截圖**，只用文字與既有的圖示字元。
9. **安全**：內容一律用 `textContent` 建立，或使用 `escapeHtml`；不得把語系字串直接塞進 `innerHTML`。若段落需要粗體或清單，用 DOM API 建立元素。
10. **版面**：沿用既有樣式（卡片、標題、清單），手機寬度可閱讀。每一節是一張卡片，最上方有目錄，點目錄可捲動到該節。

## 內容（繁體中文，`zh-TW.json` 以此為準）

其他三種語言翻譯此內容，意思一致、用該語言自然的說法；按鈕與畫面名稱必須和該語言介面上實際顯示的文字一致（從各自語系檔中對應的 key 取得原文核對）。

### 標題區

- 標題：使用說明書
- 副標：幾分鐘看懂這個網站能幫你做什麼，以及怎麼開始。

### 1. 這個網站能做什麼

- 即興問答：輸入主題，AI 幫你出題，你用說的或打字回答。
- 演講練習：貼上或撰寫講稿，反覆演練並取得回饋。
- AI 教練回饋：從結構、內容、表達三個面向評分，告訴你哪裡做得好、哪裡可以更好。
- 複習卡：把值得學習的句子留下來，之後定期複習。
- 紀錄：日曆、連續天數與成績趨勢，看見自己的進步。

### 2. 三步驟開始

1. 在首頁選「即興問答」或「演講練習」。
2. 用錄音或打字作答。
3. 按「分析我的回答 ✦」，看 AI 教練的回饋。

### 3. 即興問答

- 在「今天想聊什麼？」輸入一個主題，或按「↻ 給我靈感」。
- 按「產生題目」，每次會出三題。
- 建議每題回答 1–2 分鐘：先說結論，再用一個故事或例子支持它。
- 每天的目標是三題，首頁會顯示今天完成了幾題。

### 4. 演講練習

- 選「演講練習」後，可以輸入演講標題與講稿內容。
- 錄音或打字都可以；按「分析我的講稿 ✦」取得回饋。
- 練習紀錄會保存演講標題，方便日後找到。

### 5. 錄音與轉成文字

有兩種方式，可以在設定中切換：

- **瀏覽器即時辨識（免費）**：邊說邊轉成文字，不需要登入，也不花費額度。
- **API 高品質轉錄**：說完後交給 AI 轉成文字，通常比較準，並會自動加上標點。需要登入，會使用 AI 額度。

使用時的小提醒：

- 轉出來的文字可以直接修改，再送出分析。
- 用手機錄音時，在支援的瀏覽器上螢幕會保持開啟。
- 使用 API 高品質轉錄時，如果螢幕關閉或切到其他 App，已錄的內容會保留；回來後按「繼續錄製」就能接著錄。
- 單段錄音大約可以錄 17 分鐘。

### 6. 看懂 AI 教練回饋

- **整體表現**與三個分項：結構清晰、內容具體、表達流暢。
- **做得好的地方**與**可以改進的地方**。
- **逐句改善**：原本的說法與建議的說法並列。
- **英文文法**：英文練習時，會說明文法錯誤與正確用法。
- **改善後的全文**：可以用瀏覽器的語音朗讀，並選擇語音與速度。

### 7. 複習卡

- 在分析結果中，對想記住的句子按「加入複習」，就會建立一張複習卡。
- 到「複習」頁面，先回想正確的說法，再翻開答案，依熟悉程度選擇：忘記、困難、記得、熟練。
- 系統會依你的選擇安排下次複習的時間：越熟悉，間隔越長；選「忘記」會很快再出現一次。
- 「卡片庫」可以搜尋、篩選、編輯、封存卡片，或批次設定下次複習日期。

### 8. 日曆與成績趨勢

- 「日曆」顯示每天的練習次數與連續天數，點某一天可以看當天的練習。
- 「成績趨勢」（在設定選單中）顯示分數的變化，可以依語言與期間篩選。
- 每一筆練習都可以在練習紀錄中打開，重看當時的回答與完整報告。

### 9. 登入、AI 額度與資料

- **不登入也能用**：可以使用內建教練，資料只存在這台裝置的瀏覽器。
- **用 Google 登入**：可以使用網站提供的 AI 教練，不需要自己申請 API key。
- **AI 額度**：每人有 1 美元的累計額度，不會重置。打開「API 費用」可以看到「已用 / 額度」。用完後會自動改用內建教練。
- **雲端同步**：登入後可以選擇「僅限這台裝置」或開啟雲端同步。開啟後，換一台裝置登入同一個帳號，資料就會出現。
- **錄音不會被保存**：轉成文字後就丟棄，伺服器與資料庫都不保存錄音。

### 10. 資料備份

- 在設定選單打開「匯出與匯入」，按「匯出所有資料」下載一份備份檔。
- 換手機或清除瀏覽器資料前，建議先匯出。
- 「匯入備份」會以備份內容取代目前的資料，系統會先要求確認。

### 11. 切換語言

- 在畫面右上角的語言選單選擇：繁體中文、English、日本語、العربية。
- 介面與這份說明書都會換成你選的語言。
- （Codex 請核對：右上角的語言選單是否同時決定練習與 AI 回饋的語言。若是，加上一句「AI 出題與回饋也會使用這個語言」；若練習語言另有設定，照實際行為描述。）

### 12. 常見問題

- **有多個 Google 帳號，想換另一個？** 先登出，再按登入，就會出現選擇帳號的畫面。
- **錄音被中斷了？** 使用 API 高品質轉錄時，已錄的內容會保留，回到網頁後按「繼續錄製」。
- **出現「AI 額度已用完」？** 回饋會改用內建教練。需要更多額度請聯絡管理員。
- **出現「音檔超過 4 MB」？** 單段錄音太長，請改用瀏覽器即時辨識，或分段錄製。
- **想看這個網站更新了什麼？** 在設定選單打開「版本紀錄」。

## 測試（TDD）

單元測試（先寫、確認失敗再實作）：

- 四個語系檔都有完全相同的一組 `guide.*` key，而且沒有空字串（`scripts/check-i18n.mjs` 或新的測試）。
- `navigateTo('guide')` 顯示說明畫面；`#guide` 初始載入時直接顯示說明畫面。
- 說明畫面的輸出只使用文字節點，不含任何由語系字串產生的 HTML 標籤。

瀏覽器整合測試（`e2e/`，兩個瀏覽器專案）：

- 首頁「使用說明書」入口位於「今天想練什麼？」標題的上方，點擊後進入說明畫面。
- 切換四種語言時，說明畫面的標題與第一節標題都會改變，而且沒有顯示 `guide.` 開頭的 key。
- 直接打開 `/#guide` 會顯示說明畫面；按「回到首頁」回到首頁；按「開始練習」進入即興問答。
- 目錄連結可以捲動到對應的段落。

## 工作規則

- 分支 `feat/user-guide`。分成兩個 commit：
  1. 畫面、入口、路由、`zh-TW.json` 內容與單元測試、e2e 測試。
  2. `en-US.json`、`ja-JP.json`、`ar.json` 的翻譯，以及 CHANGELOG、README。
- 每個 commit 前 `npm test` 與 `npm run e2e` 都要通過。
- 不要 push。不要修改與本計畫無關的程式，不要重新排版既有長行。
- 全部完成後回報「USER GUIDE DONE」，附兩個 commit hash 與測試摘要。遇到計畫沒寫到、需要做設計決定的情況，停下來回報。
